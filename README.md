# EKS LLM Lab: a hands-on AI-infrastructure platform

A production-shaped lab for practising the infrastructure behind LLM training and serving, aimed at platform/infra interviews at frontier AI labs.

**Start here: [`PLATFORM-V2.md`](PLATFORM-V2.md).** It tears down any old lab clusters, then builds the v2 platform step by step.

## What you build

- **3 EKS clusters:** `platform-hub` (Argo CD + Grafana), `llm-dev` and `llm-staging` (GPU workloads)
- **Terraform for Day 0–1 only:** VPCs, EKS, Karpenter controller, IAM, Amazon Managed Prometheus, Argo CD; per-environment state in S3
- **Argo CD for everything else, versioned per environment:** Karpenter NodePools, Calico, Istio, baseline network policy + mTLS, Prometheus → AMP, Kueue + team queues, Agent Sandbox + warm pool, and the vLLM app
- **Promotion by pull request:** dev first, then staging, for app images, add-on versions and infrastructure

## Repo layout

| Path | What |
|---|---|
| `infra/bootstrap-state/` | One-time S3 + KMS bucket for Terraform state |
| `infra/modules/eks-spoke/` | Reusable workload cluster: VPC, EKS, Karpenter, artifacts bucket, trainer IAM |
| `infra/envs/dev/`, `infra/envs/staging/` | Thin per-environment roots calling the module, each with its own state |
| `infra/hub/` | Hub cluster, AMP, cross-cluster identity, Argo CD, cluster secrets, root app |
| `gitops/bootstrap/` | ApplicationSets (generated by `scripts/gen_bootstrap.py`) |
| `gitops/envs/<env>/addons.yaml` | **Add-on versions per environment** (what gets promoted) |
| `gitops/addons/` | Shared and per-environment Helm values for third-party charts |
| `gitops/charts/` | Our own charts: Karpenter NodePools, platform baseline, Kueue config, sandbox platform |
| `apps/vllm/` | vLLM chart + `envs/<env>/values.yaml` (image tag per environment) |
| `k8s/` | Manual exercises: DDP training, fine-tuned serving, mesh test clients, Kueue jobs |
| `training/`, `scripts/` | Training script, load test, sandbox benchmark, tool installer, generator |
| `.github/` | PR validation workflow, CODEOWNERS |
